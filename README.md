# Juan José Jiménez Catalán

Aspiring Healthcare IT and Imaging Informatics professional, building practical skills in PACS, DICOM, HL7 v2, Orthanc, Docker, and radiology workflows.

I create reproducible, synthetic labs to understand how clinical imaging systems exchange patient data, orders, worklists, and images.

## Technical focus

- PACS administration and medical imaging workflows
- DICOM, DICOMweb, C-ECHO, C-STORE and C-FIND
- HL7 v2, MLLP, ACK handling and message validation
- Modality Worklist (MWL)
- Orthanc, OHIF Viewer, Docker and Docker Compose
- Troubleshooting, testing and technical documentation

## Featured projects

### [PACS / DICOM Lab](https://github.com/juanjosejimenezcatalan-boop/pacs-dicom-lab)

Local PACS environment using Orthanc, DICOMweb and OHIF Viewer. Includes public de-identified CT data, metadata inspection, persistent storage, API queries and incident recovery.

### [DICOM Connectivity & Routing Lab](https://github.com/juanjosejimenezcatalan-boop/dicom-connectivity-lab)

Two-node Orthanc lab demonstrating DICOM C-ECHO and C-STORE between a simulated modality and a destination PACS, including an AE Title failure scenario.

### [HL7 Radiology Workflow Lab](https://github.com/juanjosejimenezcatalan-boop/hl7-radiology-workflow-lab)

Synthetic HL7 v2 radiology workflow with ADT, ORM and ORU messages over MLLP, ACK/ERR responses, validation and audit logging.

### [HL7-to-DICOM Modality Worklist Lab](https://github.com/juanjosejimenezcatalan-boop/hl7-to-dicom-mwl-lab)

Integration lab that maps an HL7 ORM^O01 radiology order to an Orthanc DICOM Modality Worklist entry, retrieved by a simulated CT modality using C-FIND.

## Approach

All projects use synthetic or public de-identified data only. They are designed as learning environments and are not intended for clinical use.
